databaseEstructura de Base de Datos
Colecciones Principales
  • empresas: Datos de las PYMEs registradas
  • users: Usuarios con roles (admin, contador, usuario)
  • clientes: Base de clientes por empresa
  • facturas: Facturas electrónicas y estados
  • contratos: Contratos generados con IA
  • analytics: Eventos y métricas del sistema
Características Técnicas
  • • Índices optimizados para consultas rápidas
  • • Referencias cruzadas entre colecciones
  • • Validación de esquemas con Mongoose
  • • Agregaciones para reportes complejos
  • • Backup automático en MongoDB Atlas
